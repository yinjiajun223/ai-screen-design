# AI Screen Design

基于 Vue 3 的可视化大屏设计编辑器原型。项目采用物料、页面 DSL 和编辑器状态分离的方式，支持将物料拖入画布后进行选择、移动、缩放和属性编辑。

## 当前功能

- 编辑器基础布局：物料面板、图层面板、画布和属性面板
- 面板显隐切换，支持物料、图层和属性面板独立开关
- 物料拖拽：从物料面板拖入画布创建节点
- 当前物料分类：信息、图表
- 图表物料：柱状图、条形图、折线图、面积图、饼图、散点图和漏斗图
- 图表渲染：基于 ECharts 的 `dataset.source` 与 `series.encode` 数据映射
- 节点选择：单选、框选、多选和点击画布取消选择
- 节点操作：拖动、调整尺寸、批量移动和批量缩放
- 画布辅助：可缩放标尺、画布尺寸设置、背景色设置和窗口尺寸自适应
- 图层管理：选择节点、拖动调整图层顺序
- 节点右键菜单：复制、移除、置顶、置底、锁定和解锁
- 节点属性编辑：文本内容、颜色、位置和尺寸
- 撤销与重做：支持属性表单修改的撤销和重做，按钮会根据历史记录自动启用或禁用
- 数据源管理：可在工具栏新增、编辑和删除静态或 API 数据源，并在属性面板绑定到图表
- API 数据源：支持 GET/POST 请求、请求参数、响应路径提取、轮询加载和请求预览
- 数据源状态：图表加载 API 数据时显示加载状态；删除或解绑数据源后自动回退至物料默认数据
- 本地 Mock：内置带随机延迟的 `/api/data` 示例接口，便于演示请求、轮询和加载状态
- 工具栏：支持页面 JSON 查看、导入 JSON 文件入口和导出页面配置
- 深色编辑器主题和 Element Plus 控件样式适配

## 快速开始

项目使用 pnpm 管理依赖，建议使用 Node.js 22.18+ 或 Node.js 24.12+。

```bash
pnpm install
pnpm dev
```

启动后打开终端输出的本地地址，通常为 `http://localhost:5173`。

### 常用命令

```bash
# 类型检查和生产构建
pnpm build

# 仅执行类型检查
pnpm type-check

# 预览生产构建结果
pnpm preview

# 运行代码检查
pnpm lint
```

## 使用流程

1. 从左侧物料面板选择物料，将物料拖入中间画布。
2. 点击节点进行选择，拖动节点调整位置，使用控制点调整尺寸。
3. 使用 Shift 框选或多选节点，可批量移动和缩放。
4. 在右侧属性面板修改节点内容、颜色、位置和尺寸；未选中节点时可修改画布尺寸和背景色。
5. 在图层面板中选择节点或拖动节点调整层级。
6. 右键节点执行复制、删除、置顶、置底和锁定操作。
7. 点击工具栏的数据源配置，新增静态或 API 数据源；API 数据源可设置请求方式、参数、响应路径和轮询周期，并执行请求预览。
8. 在图表属性面板选择数据源完成绑定；清空绑定或删除已绑定数据源时，图表将恢复为物料默认数据。
9. 使用顶部撤销、重做按钮回退或恢复属性修改。

### API 数据源说明

- 静态数据源通过 JSON 编辑器维护，适合固定展示数据。
- API 数据源支持 `GET` 和 `POST`：GET 参数会拼接为查询参数，POST 参数会作为请求体发送。
- 请求参数会合并数据源配置、页面 URL 参数和手动传入参数，后者优先级更高。
- 响应路径用于从接口响应中提取实际图表数据，例如接口返回 `{ "list": [...] }` 时可设置为 `list`。
- 多个组件使用相同请求配置时会复用进行中的请求，避免同一时刻发送重复请求。

## 项目结构

```text
src/
├─ editor/                  编辑器布局、工具栏、画布和面板
│  ├─ canvas/               画布、标尺、选择和移动逻辑
│  └─ panels/               物料、图层、属性面板及表单组件
├─ materials/               物料注册和物料组件（含图表物料）
├─ schema/                  页面、画布和节点 DSL 类型
├─ stores/                  Pinia 编辑器状态
├─ composables/             可复用逻辑，例如撤销重做、数据源加载
├─ mock/                    本地 Mock 接口
├─ styles/                  全局样式和主题变量
└─ utils/                   DSL 属性读写等工具函数
```

物料通过 `src/materials/*/index.ts` 注册。每个物料可以提供节点 schema、渲染组件和属性 setter，编辑器会通过注册表动态获取物料和对应组件。
